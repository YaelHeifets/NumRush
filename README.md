# NumRush

**Think Fast. Click Smart.**

NumRush is a fast-paced number game built with HTML, CSS and JavaScript.

## How to Play

1. Enter your name and start the game.
2. Ten random 4-digit numbers will appear.
3. Click the numbers from smallest to largest.
4. A correct number will turn green.
5. A wrong number will turn red and play a sound.
6. After three mistakes, the game is over.
7. Complete the sequence as fast as possible and try to beat your best time.

## Features

- Random number generation
- Game timer
- Best time tracking
- Error counter
- Sound feedback
- Win and Game Over screens
- Confetti animation on victory
- Play Again option

## Technologies

- HTML
- CSS
- JavaScript
